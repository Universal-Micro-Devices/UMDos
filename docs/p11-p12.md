# P11 / P12 实现说明（v2.6.112-dev.7）

## P11：终端模拟器与 shell

### 1. 终端（`term.c`）

* 字符网格 78×22，scale 2 绘制（78×16 = 1248 px < 1280，22×32 = 704 px < 720）。
* 每个字符同时写 COM1，自动化测试可以直接断言终端内容。
* 输入：可打印字符逐字符增量绘制（不整屏重绘），Backspace 只擦一个字符，
  Enter 后整屏重绘一次并执行命令；Esc 返回桌面。
* 从桌面按 **F10** 打开，标题栏提示 `Esc = back to desktop`。

### 2. Shell（`sh.c`）

| 命令 | 说明 |
|---|---|
| `help` | 命令列表 |
| `ls [path]` | 列目录（DIR/FILE + 大小 + 名字） |
| `cd <dir>` / `pwd` | 切换/打印当前目录（路径规范化支持 `.`、`..`） |
| `cat <file>` | 输出文件内容（走 VFS） |
| `echo <text>` | 回显 |
| `mkdir <path>` / `rm <path>` | 建目录/删文件（`/config` 下受权限限制） |
| `cp <src> <dst>` / `mv <src> <dst>` | 复制 / 复制后删除 |
| `ps` | 打印 `/proc/tasks` 风格进程表 |
| `whoami` | 当前登录名与角色 |
| `free` | 页帧与堆信息 |
| `reboot` | 提示 ACPI 关机在 P14 |
| `exit` | 退出终端回桌面 |

路径处理：shell 维护 `sh_cwd`，相对路径拼接后规范化；所有文件操作走 VFS。

### 3. 顺带修复

`vfs_readdir` 原来用“子项个数”当循环上界，导致 `cd CONFIG; ls` 看不到 AUTH；
现在按**全局目录项索引**遍历（0..63）。

## P12：多用户、权限与锁屏

### 1. 身份与角色

* `auth.c` 记录登录名与角色（`administrator` 条目 → 角色 1）。
* 登录成功后 `vfs_set_role(auth_role())`：
  * 角色 1（管理员）：可以写 `/config`；
  * 角色 0（普通用户）：`/config` 下的创建/写入/删除一律拒绝（`vfs_open(O_CREAT)`、
    `vfs_write`、`vfs_mkdir`、`vfs_unlink` 都检查）。
* shell 的 `whoami` 显示 `user (user)` 或 `administrator (administrator)`。

### 2. 登录限速

连续 3 次密码错误 → 锁定 10 秒（基于 RTC 秒，跨分钟安全），期间登录被拒绝，
串口输出 `[kernel] login: 3 failures, locked 10s`，锁定结束后自动解锁并记录。

### 3. 锁屏

桌面按 **Ctrl+L** 进入锁屏：整屏渐隐 + 密码框，输入当前用户密码解锁；
错误显示 `wrong password`，串口记录 `lock: locked` / `lock: unlocked` / `lock: wrong password`。

### 4. 安全自检（`sec.c`）

```
[kernel] security selftest: iomap/userpage/config-perm ok (iomap=1 user=1 kern=1 cfg=1)
```

* `iomap`：TSS 的 I/O 位图基址指向 TSS 末尾 → ring3 执行 `in/out` 会 #GP；
* `user`/`kern`：用户页 PTE 带 U 位、内核映像页 PTE 不带 U 位；
* `cfg`：普通用户写 `/config` 被拒绝。

## 验收

```sh
python tools/test_p11p12.py
```

覆盖：shell 全部命令、锁屏解锁、3 次失败锁定、管理员登录与 `whoami`、
管理员可在 `/config` 建目录、安全自检通过。

## 已知限制

1. shell 没有管道、重定向、通配符与历史记录；一次一行。
2. 终端只有 78×22 一个尺寸，没有滚动缓冲（超出旧行被丢弃）。
3. fork 出的进程仍未参与用户态调度；`exec` 仍是占位（需要从 VFS 读 ELF）。
4. 权限只基于 `/config` 路径前缀 + 管理员/普通用户两种角色，没有完整 ACL。
5. 锁屏与限速都基于 RTC 秒，精度为 1 秒。
6. 文件管理器增强（地址栏/多标签/右键菜单）不在本版本范围内，留到后续。
