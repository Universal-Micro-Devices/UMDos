# P13 / P14 实现说明（v2.6.112-dev.8）

## P13：UEFI 与 Legacy 并存

### 1. UEFI 加载器（`efi/efi_loader.c` → `efi/bootx64.efi`）

编译：`zig cc -target x86_64-uefi`（lld-link 自动使用 `efi_application` 子系统，
入口符号 `EfiMain`）。

流程：

1. `ConOut->OutputString` 输出横幅；
2. `BootServices->LocateProtocol(GOP_GUID)` 取 GOP，读 `Mode->Info` 的分辨率与
   `Mode->FrameBufferBase`；
3. `AllocatePages(AllocateAddress)` 申请固定区域 `0x1000..0x8FFFF`；
4. 把**编译时内嵌**的内核镜像与 UMDFS 镜像拷到 `0x10000` / `0x40000`
   （`efi/gen_embed.py` 生成 `efi/efi_embed.h`，内核 160KB + FS 128KB）；
5. `0x1000..0x6FFF` 建 4 级恒等映射页表（与 `head.asm` 相同的 2MB 大页布局），
   填 `bootinfo`（分辨率、帧缓冲、镜像位置、`env_flags=1`）；
6. `ExitBootServices` → 设置 CR3/CR4.PAE/EFER.LME/CR0 → `jmp 0x10000` 进内核。

### 2. FAT ESP 与混合 ISO

* `efi/mkfat.py`：手写 FAT12 镜像（1.44MB），内含 `/EFI/BOOT/BOOTX64.EFI`；
* `build.py`：把 `EFI.IMG` 加进 ISO，并在 El Torito 目录里追加 **UEFI 段**：

```
offset 0   验证项 (platform 0)
offset 32  初始项 (BIOS, 软盘仿真, LBA 26)
offset 64  段头 0x90 / platform 0xEF
offset 96  UEFI 项 0x88, no-emulation, system 0xEF, 2880 扇区
```

### 3. 验收（结构级）

`tools/test_p13p14.py` 检查：

* `bootx64.efi` 是 PE32+、machine=0x8664、subsystem=10（EFI_APPLICATION）；
* `efi.img` 是 FAT12 且根目录含 `EFI`；
* ISO 的 El Torito 目录同时存在 BIOS 初始项与 UEFI 段。

### 4. 已知限制（重要）

本仓库环境**没有 UEFI 固件（OVMF）**，无法端到端验证 EFI 启动路径。
已交付的部分：加载器源码、PE 产物、FAT ESP、混合 ISO 的 UEFI 目录项；
未验证的部分：`ExitBootServices` 后的内存布局假设（固定物理地址是否可分配）、
GOP 帧缓冲在真实固件下的行为。需要发布阶段在带 OVMF 的 QEMU 或真机上回归。

## P14：ACPI / APIC 与电源

### 1. 表解析（`src/kernel/acpi.c`）

* 在 `0xE0000..0xFFFFF` 每 16 字节扫描 `"RSD PTR "` 找 RSDP；
* ACPI 2.0+ 优先用 `XSDT`，否则 `RSDT`；
* 遍历根表找 `FACP`（FADT：`PM1a_CNT_BLK`、`PM1b_CNT_BLK`、flags bit10 的
  `RESET_REG`）与 `APIC`（MADT：统计类型 0 的 LAPIC 条目）；
* 串口输出：`acpi: rsdp ok xsdt tables=2 fadt madt lapic=2 PIC fallback kept`。

**PIC 回退保留**：本版本不启用 LAPIC/IOAPIC 中断投递，只做表解析与计数；
APIC 中断重定向留到 P15（SMP）。

### 2. 电源

| 动作 | 实现 |
|---|---|
| 关机 | FADT `PM1a_CNT`/`PM1b_CNT` 写 `SLP_TYPa\|SLP_EN`；回退 QEMU `0x604`、旧 Bochs `0xB004` |
| 重启 | FADT `RESET_REG`（ACPI 2.0+）；回退键盘控制器 `0x64 <- 0xFE` |
| 入口 | shell 的 `shutdown` / `reboot` 命令 |

### 3. 测试环境支持

`tools/emu.py` 在 `0xE0000` 区域生成 RSDP/XSDT/FADT/MADT（FADT 指向 `0x604`，
`RESET_REG` 指向 `0xCF9`），`tools/emu_ui.py` 监听 `0x604/0xB004/0x64/0xCF9`
记录关机/复位，测试据此断言。

### 4. 验收

`tools/test_p13p14.py`：

```
[OK] ACPI 解析出 FADT/MADT 并保留 PIC 回退
[OK] lapic 计数 > 0
[OK] shutdown 命令触发 ACPI S5
[OK] reboot 命令触发复位
```

## 已知限制

1. EFI 路径未端到端验证（无 OVMF），见上文。
2. LAPIC/IOAPIC 仅解析未启用；中断仍走 PIC（P15 处理）。
3. `SLP_TYPa` 固定取 5（没有 AML 解释器，无法读 `\_S5_`），个别固件可能不同。
4. 桌面电源按钮尚未加，本版本用 shell 命令；界面按钮留到后续。
