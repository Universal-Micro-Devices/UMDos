# P17：AHCI 多端口 + 多盘块设备（v2.6.112-dev.14）

## 1. 驱动

| 项 | 说明 |
|---|---|
| 端口扫描 | `ahci_init()` 遍历 `PI` 所有已实现端口，检查 `PxSSTS.DET=3` 且 `PxSIG=SATA` |
| 每盘资源 | 每盘独立命令列表（1KB）、FIS（256B）、命令表 + PRDT（256B）、IDENTIFY 缓冲（512B） |
| 多盘 API | `ahci_disk_count()`、`ahci_disk_sectors(i)`、`ahci_disk_model(i)`、`ahci_disk_read(i,…)`、`ahci_disk_write(i,…)` |
| 块设备 | `dev.c` 为每盘注册 `ahci0`、`ahci1`…（回调按 `dev_t*` 反查盘号） |
| 回退 | 无 AHCI 控制器时仍走 ATA PIO（`/dev/ata`） |

启动日志：

```
[kernel] ahci: disk0 model="UMDos Virtual SATA" sectors=2880
[kernel] ahci: disk1 model="UMDos Virtual SATA B" sectors=2048
[kernel] ahci: disk0 read ok
[kernel] ahci: disk1 read ok
[kernel] dev: registered serial/kbd/mouse/ahci0/ahci1/ata
```

## 2. 模拟器支持（tools/emu_ui.py）

| 项 | 说明 |
|---|---|
| 控制器 | `CAP=2 ports`、`PI=0x3`，端口 0/1 各自 `PxSIG/PxSSTS/PxTFD` |
| 端口执行 | 按 `PxCI` 所在端口解析该端口的命令列表/FIS/PRDT |
| 磁盘 0 | 主镜像（`self.img`，2880 扇区） |
| 磁盘 1 | 第二虚拟盘（`self.img2`，2048 扇区，`UMD2SATA` 标记 + 0x55AA） |
| 完成信号 | 每端口 `PxIS` bit3；IDENTIFY 按端口返回型号与容量 |

## 5. 已知限制

1. 仅处理 SATA（非 ATAPI/PM 端口）。
2. 轮询模式，无 NCQ/中断；单次命令最多 255 扇区。
3. 真实硬件上的多盘热插拔/错误恢复未覆盖。
