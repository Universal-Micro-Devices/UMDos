# P18：AHCI 错误恢复 + 读写自检（v2.6.112-dev.15）

## 1. 错误恢复

| 机制 | 实现 |
|---|---|
| 命令失败检测 | 轮询 `PxIS` 完成后检查 `PxTFD.ERR`；超时（20M 轮询）也视为失败 |
| 端口复位 | `PxCMD.ST=0` → 等 `CR` 清除 → `PxSCTL.DET=1`（COMRESET）→ 等待约 1ms → `DET=0` → 等 `PxSSTS.DET=3` → 重设 `PxCLB/PxFB/ST/FRE` |
| 重试 | 失败后复位端口并重试一次；第二次仍失败返回错误码（-2 任务文件错 / -3 超时） |
| 日志 | `[kernel] ahci: port reset (cmd error)` |

## 2. 自检扩展（`ahci_selftest`）

1. `disk0/disk1 read ok`：读 LBA 0 校验 0x55AA；
2. 越界读（`sectors + 16`）→ 期望返回错误，打印 `disk1 range check ok`；
3. 写最后一扇区 → 读回 → 逐字节比较，打印 `disk1 write/read ok`；
4. 恢复后重读 LBA 0 → `disk1 recheck ok`。

串口实际输出：

```
[kernel] ahci: disk0 model="UMDos Virtual SATA" sectors=2880
[kernel] ahci: disk1 model="UMDos Virtual SATA B" sectors=2048
[kernel] ahci: disk0 read ok
[kernel] ahci: disk1 read ok
[kernel] ahci: port reset (cmd error)
[kernel] ahci: disk1 range check ok
[kernel] ahci: disk1 write/read ok
[kernel] ahci: disk1 recheck ok
[kernel] dev: registered serial/kbd/mouse/ahci0/ahci1/ata
```

## 3. 模拟器支持

* 读/写命令的 `lba + count` 超出该盘容量时，返回 `PxTFD.ERR`（0x51）且不搬运数据；
* 端口复位相关寄存器（`PxSCTL/PxSSTS`）保持“链路正常”，使复位流程可完成。

## 4. 验证

```sh
python tools/test_p15p16.py   # 含：越界错误路径 / 端口复位重试 / 写读回环 / 恢复后可用
```

全部通过。

## 5. 已知限制

1. 仍为轮询模式，无 IRQ/NCQ；单命令 ≤255 扇区。
2. 错误恢复仅重试一次；多次失败会向调用方返回错误，不做热插拔重新枚举。
3. COMRESET 的 1ms 等待用忙循环近似，未用 PIT 定时。
