# P5 / P6 实现说明（v2.6.112-dev.4）

## P5：内核线程、调度、TSS、ring3、系统调用

### 1. GDT 重建（顺带修掉 dev.3 的隐患）

dev.3 的 IDT 门使用选择子 `0x08`，而 loader 的 GDT 里 `0x08` 是 **32 位**代码段。
长模式下中断门指向 L=0 的段会进入兼容模式，64 位入口桩会按 32 位解码。
dev.4 在内核里重建 GDT：

| 选择子 | 用途 |
|---|---|
| `0x00` | 空 |
| `0x08` | 64 位代码段 DPL0（IDT 门与内核 CS） |
| `0x10` | 数据段 DPL0 |
| `0x18` | 64 位代码段 DPL3（用户） |
| `0x20` | 数据段 DPL3（用户） |
| `0x28` | TSS（64 位，`ltr` 装载） |

### 2. 内核线程与轮转调度

* `src/kernel/task.c`：最多 8 个任务，每个任务 8KB 内核栈（从 `kmalloc` 拿）。
* `src/kernel/switch.asm: switch_ctx(old_rsp, new_rsp)`：保存/恢复 rbx、rbp、r12–r15，切换栈后 `ret` 到目标任务入口。
* `sched_yield()`：保存 IF → `cli` → 选下一个 READY → `switch_ctx` → 恢复 IF。
* `sched_tick()`：IRQ0 每 5 个 tick 触发一次抢占。
* `task_exit()`：标记 DEAD，之后永不再被调度。
* 演示：`kthreadA` / `kthreadB` 各打印 2 次、`sched_yield` 让出，然后退出；
  main 与之轮转。串口可见 `main → kthreadA → kthreadB → main …` 与最终 `switches=9`。

### 3. 系统调用

* IDT 第 `0x80` 项是 DPL=3 的中断门；`isr.asm` 里新增 `isr_0x80` 桩，并把保存的
  寄存器区指针（第 6 个参数）传给 `isr_dispatch`。
* 约定：`rax` = 调用号，`rdi/rsi/rdx/r10` = 参数，返回值写回 `rax`。
* 实现：`exit`、`write`、`getpid`、`sleep`、`brk`；`open/read/close` 返回 -1（P7 的 VFS 再实现）。
* `write(1, buf, len)` 输出到 COM1；用户指针只做 `USER_BASE..USER_LIMIT` 上界检查。

### 4. ring3

* `src/kernel/user.c`：ELF 加载后构造 iretq 帧（SS=0x23、CS=0x1B、RFLAGS=0x202、
  用户栈），`user_enter` 直接切到 ring3；`exit` 系统调用经 `user_leave_to_kernel`
  恢复进入前的内核栈并返回 `user_run`。
* TSS 的 `rsp0` 在进入内核时指向内核栈，保证系统调用从用户栈切到内核栈。

## P6：ELF64 加载器与最小 libc

* `src/kernel/user.c: elf_load()`：校验 ELF64 头、遍历 `PT_LOAD`，
  逐页 `pmm_alloc` + `vmm_map_page(va, pa, 0x07)`，拷贝文件内容并清零 BSS。
* 用户地址空间：`USER_BASE = 0x0000008000000000`（PML4 索引 256，与低端恒等映射互不影响），
  用户栈在 `USER_BASE + 2MB` 处，占 2 页。
* `user/` 目录：`link.ld`（链接到 USER_BASE）、`libc.c`（最小 libc：
  `_start`、`write`、`exit`、`malloc`、`free`、`open`、`read`、`close`、`getpid`、`sleep`、`brk`）、
  `prog.c`（演示：打印、getpid、malloc、退出）。
* `tools/gen_userprog.py`：把编译好的 `bin/user.elf` 转成 `src/kernel/userprog.h` 内嵌到内核。
* 用户程序用 `-mcmodel=large` 编译，避免高地址下的 32 位重定位。

## 模拟器限制

Unicorn **没有 GDT/IDT 模型**：`iretq` 的 CPL 切换会失败（实测进入 #DF 后停机）。
测试工具通过 bootinfo `env_flags`（+112）bit0 让内核改跑 `user_selftest()`：
ELF 解析、页表映射、用户栈、用户指针校验、`write`/`getpid` 分发都会执行，
只有“真正切到 CPL3”这一步在模拟器里跳过。ring3 本身需要在 QEMU/真实硬件上验证。
